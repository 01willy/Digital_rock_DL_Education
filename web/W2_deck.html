A SINGLE NEURON

가중치 하나가 학습한다는 것

신경망의 최소 단위 — 입력에 가중치(w)를 곱하고 편향(b)을 더해 출력. 학습 = 이 w·b 를 데이터로 조정.

y = f( w·x + b )
한 걸음씩 정답에 가까워진다
step예측 ŷ정답 y오차
10.421.000.58
20.611.000.39
30.781.000.22
…0.941.000.06
* 개념 예시 (실제 학습값 아님)
매 step마다 오차를 줄이는 방향으로 w·b 를 조금씩 옮기면, UNet의 24만 개 가중치도 같은 원리로 학습됩니다.

SKIP-CONNECTION

UNet의 핵심 — detail을 건너뛰어 전달

Encoder가 압축하며 잃어버린 엣지·텍스처를, 같은 크기의 Decoder 단계에 그대로 이어 붙여(concat) 복원합니다.

# UpBlock.forward
x = self.up(x) # 크기 ↑
x = torch.cat([x, skip], dim=1) # 채널로 합치기
skip 없으면 → 경계가 뭉개진 흐릿한 복원
skip 있으면 → 선명한 pore 경계

§6.5 ADVANCED · 직접 바꾸고 분석하기

편의 함수를 펼쳐, 스스로 실험한다

train_quick 에 가려졌던 학습 루프를 train_custom 으로 펼쳐 손실·구조·k 를 직접 바꿉니다. 정답 실행이 아니라 "무엇을 바꿨고/무엇이 변했고/왜" 를 분석.

A
학습 루프 직접 제어
train_custom 으로 base·epochs·lr 을 펼쳐 모델 크기 ↔ 성능 ↔ 과적합 관찰
B
손실 함수 비교
L1 vs MSE, 나아가 L1 + λ·(1−SSIM) 복합 손실을 직접 구현
C
k 일반화
k=3 학습 → k∈{2,3,5,7} 평가. sparsity 일반화의 한계 측정
D
per-slice 실패 분석
슬라이스별 |Δφ| 를 그려 모델이 '어디서' 실패하는지 구조적 원인 탐색
챌린지
네 도메인 모두에서 Linear를 이기는 설정을 찾아라 — 학습 적합 ↔ 일반화 ↔ 과적합의 균형이 관건.
