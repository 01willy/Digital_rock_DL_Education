05 / 21
TRAINING LOOP

학습의 네 박자

"학습" = 모델의 가중치(weight)를 조정해 입력 → 출력 함수를 데이터로부터 만들어 가는 과정.

01
Forward
모델에 입력을 넣어 예측 출력을 만든다.
02
Loss
예측과 정답(GT)의 차이를 숫자로 계산한다.
03
Backward
loss를 줄이는 gradient(기울기)를 계산한다.
04
Optimizer step
가중치를 loss가 줄어드는 방향으로 한 걸음 옮긴다.
이 사이클을 수많은 batch에 반복
가중치가 조금씩 좋아지며, 예측이 점점 정답에 가까워집니다. 1 epoch = 데이터 전체를 한 번 학습.

06 / 21
L1 · L2 · Adam

무엇을 줄이고, 어떻게 한 걸음 옮기나

L1
L1 loss · 평균 절대오차
|pred − target| 평균. outlier에 강하고 부드럽지만 다소 흐림. 본 W2의 기본 손실.
L2
L2 / MSE · 제곱오차
(pred − target)² 평균. 선명하지만 outlier에 민감, 안정성↓.
≈
SSIM loss · 구조 유사도
픽셀 정확도보다 "모양 유사성"을 강조. W3에서 추가합니다.
학습 설정 (model_utils.py)
# 손실 + 최적화
criterion = nn.L1Loss()
optimizer = Adam(lr=1e-3)
학습률(lr)이 관건
너무 작으면 학습이 느리고, 너무 크면 loss가 NaN으로 발산합니다. 보통 1e-4 ~ 5e-3.

UNetMini · model_utils.py

U자 모양 — 압축과 복원

UNetMini(in_ch=2, base=8) · preset fast
▼
Encoder — 수축 경로
Conv → MaxPool 반복. 크기 64→32→16, 채널 8→16→32. 높은 수준의 특징 추출.
▲
Decoder — 확장 경로
ConvTranspose로 크기를 16→32→64로 키우고, 채널을 줄이며 픽셀 출력 생성.
σ
출력 — sigmoid 0~1
마지막 1×1 conv + sigmoid 로 한 장의 슬라이스(가운데)를 만듭니다.
