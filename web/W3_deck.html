§1 · 손실의 성질
픽셀 단위로 본 흐림의 원인
이웃 두 장만으로는 가운데 픽셀이 pore(1)인지 solid(0)인지 확정할 수 없는 경우가 생긴다. 절반 확률로 0 또는 1인 픽셀 하나에 대해, 모델이 어떤 값 ŷ를 낼 때 손실이 최소가 되는지 계산한다.
L2 (MSE) · 기대 손실
$\mathbb{E}[(y-\hat{y})^2] = \tfrac{1}{2}\hat{y}^2 + \tfrac{1}{2}(1-\hat{y})^2$  →  최소는 $\hat{y}=0.5$, 정확히 회색
L1 (MAE) · 기대 손실
$\mathbb{E}[|y-\hat{y}|] = \tfrac{1}{2}\hat{y} + \tfrac{1}{2}(1-\hat{y}) = \tfrac{1}{2}$  →  $0\le\hat{y}\le1$ 어디든 동일, 중간값이어도 벌점 없음
결론. 픽셀 단위 손실(L1·L2)은 애매한 곳에서 회색을 벌하지 않거나(L1), 오히려 보상한다(L2). 모델은 중간값으로 수렴한다.
모델의 출력 ŷL1 기대 손실L2 기대 손실
0.0 (solid 확신)0.500.50
0.5 (회색)0.500.25 ← 최소
1.0 (pore 확신)0.500.50
정답이 50:50으로 갈리는 픽셀 하나의 기대 손실. L2는 회색(0.5)이 유일한 최적해이고, L1은 확신과 중간값의 벌점이 같다. 어느 쪽도 확신을 유도하는 압력을 주지 않는다.

§1 · 2D로 확장
정답이 여럿일 때 L1의 선택: 평균
픽셀별 최적해
$\hat{y}^{*}=\arg\min_{\hat{y}}\ \mathbb{E}\big[\,\|y-\hat{y}\|\,\big]=\mathrm{median}(y)$
정답 후보들의 평균 · 중앙값
모든 후보를 반씩 섞은 이미지
pore가 A에 있을 수도, B에 있을 수도 있으면, 손실을 최소화하는 답은 A도 B도 아닌, 둘을 겹친 회색이다.
필요한 압력
평균이 아니라 그럴듯한 후보 하나를 확신 있게 선택하도록 유도해야 한다. 픽셀 손실은 이 압력을 만들지 못한다. 새로운 종류의 신호가 필요하다.

§1 · 물성 영향
흐림이 물성에 미치는 영향
Digital Rock의 목적은 이미지 자체가 아니라 이미지로 계산하는 물성(공극률·표면적·투과율)이다. 회색 경계는 이 물성을 직접 왜곡한다.
① 임계값 민감성
경계가 0.5 근처에서 흔들림
회색 픽셀은 이진화 임계값을 0.45→0.55로만 바꿔도 pore↔solid가 뒤집힌다. 공극률이 임계값에 의존하게 된다.
② 연결성 훼손
가는 목이 끊기거나 붙음
유체는 pore의 가장 좁은 길목(throat)으로 흐른다. 흐린 경계는 목을 끊거나 이어 붙여 투과율을 크게 왜곡한다.
③ 작은 구조 소실
작은 pore가 평균에 묻힘
몇 픽셀 크기의 pore는 평균화 과정에서 회색으로 옅어지다가 사라진다. 표면적·비표면적 통계도 함께 틀어진다.
위 ②번의 예 · 가는 목(throat)이 흐려지면 물길이 끊겨 투과율이 크게 달라진다
§2 로
따라서 픽셀 손실 밖에서 "이 이미지가 실제 암석 단면처럼 보이는가"를 판정하는 새 신호가 필요하다. 이 신호를 만드는 것이 두 번째 신경망, 판별자다.

§2 · 목적 함수
목적 함수: min–max
$$\min_{G}\;\max_{D}\;\;\textcolor{#1f3a5f}{\mathbb{E}_{y}\big[\log D(y)\big]}\;+\;\textcolor{#d4760f}{\mathbb{E}_{x}\big[\log\big(1-D(G(x))\big)\big]}$$
왼쪽 항 · 진짜를 진짜로 오른쪽 항 · 가짜를 가짜로
min–max의 직관 · 생성자 G는 판별자 점수를 +방향으로, 판별자 D는 −방향으로 당기며 D(G(x))≈0 균형점에서 멈춘다
판별자 D · 최대화 (max)
진짜 $y$ 에는 $D(y)\!\to\!1$, 생성 $G(x)$ 에는 $D(G(x))\!\to\!0$. 두 항을 모두 키우는 방향이 잘 구별하는 방향이다.
생성자 G · 최소화 (min)
G가 조정할 수 있는 것은 두 번째 항뿐이다. $D(G(x))\!\to\!1$ 로 만들어 그 항을 낮추는 방향이 판별자를 속이는 방향이다.
경쟁의 종착점
이론상 균형에서 생성 분포는 진짜 분포와 일치하고, $D$ 는 어느 쪽인지 못 맞혀 모든 입력에 ½ 을 내놓는다.
원식의 log 손실은 초반 gradient가 약해 정체되기 쉽다. §3에서는 같은 목적을 안정적으로 구현한 hinge 손실을 사용한다.

§3 · 구성 요소 ①
조건부 판별: 이웃을 입력에 포함
조건이 없는 경우
판별자는 "진짜 암석처럼 보이는가"만 판정한다. 생성자는 이웃과 무관한 그럴듯한 임의 단면을 생성해도 통과하고, 이 경우 보간 문제가 성립하지 않는다.
이웃을 함께 입력하는 경우
채점 기준이 "이 두 이웃 사이에 올 법한 단면인가"로 바뀐다. 사실성과 이웃과의 일관성을 동시에 판정한다.
$D(\ \textcolor{#d4760f}{x}\ ,\ \textcolor{#2e8b57}{y}\ )$
x = 조건 (이웃 2장) y = 판정 대상
torch.cat([x, y], dim=1)
이웃 2채널 + 판정 대상 1채널 = 3채널 입력. 구현은 concat 한 줄이다.
같은 원리의 다른 사례. 흑백→컬러, 스케치→사진, 지도→항공사진. pix2pix 계열은 모두 "조건에 부합하는 출력인가"를 판정한다.

§3 · 구성 요소 ②
PatchGAN: patch 단위 판정
점수 하나 vs 점수 map
이미지 전체에 점수 하나만 내면 "어느 영역이 가짜인지"에 대한 신호가 손실된다. PatchGAN은 겹치는 영역(patch)마다 점수를 내 국소 결함을 정확히 짚는다.
본 문제에 적합한 이유
L1이 훼손하는 것은 전역 구도가 아니라 국소 경계와 미세 텍스처다. 판정도 같은 스케일에서 이루어져야 한다.
§2 슬라이드 16의 점수 map이 정확히 이것이다. 15×15 격자의 각 칸이 한 patch의 판정이다 (그림은 4×4로 단순화).

§3 · Architecture
판별자 구조: 합성곱 4층
W2 합성곱 문법과 동일하다. stride-2 합성곱으로 크기를 절반씩 줄이고 채널을 두 배씩 늘린다. 마지막 1채널이 점수 map이다. 파라미터 약 168K.
마지막 층에 활성화가 없는 이유. 점수를 0~1로 압축하지 않고 실수 값(logit) 그대로 둔다. 다음 장의 hinge 손실이 이 값을 그대로 사용한다.
모든 층의 sn( )은 spectral normalization이다. 판별자가 과도하게 강해지지 않도록 하는 장치다 (§4에서 상세히 다룬다).

§3 · Loss
hinge 손실
판별자 손실
$$\mathcal{L}_D=\mathbb{E}\big[\max(0,\,1-D(y))\big]+\mathbb{E}\big[\max(0,\,1+D(G(x)))\big]$$
생성자 적대 손실
$$\mathcal{L}_G^{\text{adv}}=-\,\mathbb{E}\big[D(G(x))\big]$$
진짜를 +1 이상, 가짜를 −1 이하로 여유(margin)를 두고 밀어내되, 이미 margin을 넘은 표본은 더 갱신하지 않는다. log 원식보다 gradient가 안정적이어서 실전 표준으로 사용된다.

벌점 계산 예시
상황D의 점수D의 벌점계산
진짜에 확신D(y) = +1.50max(0, 1−1.5) = 0
진짜에 미온적D(y) = +0.80.2max(0, 1−0.8) = 0.2
가짜를 확실히 판별D(G(x)) = −1.50max(0, 1+(−1.5)) = 0
가짜에 속음D(G(x)) = +0.31.3max(0, 1+0.3) = 1.3
margin(±1)을 넘긴 표본은 벌점 0이다. 판별자는 애매한 표본에만 집중한다.
생성자 쪽에서 보면
$\mathcal{L}_G^{\text{adv}}=-D(G(x))$ 이므로:
D(G(x)) = −0.4 → 손실 +0.4 (들킴, 벌점)
D(G(x)) = +0.8 → 손실 −0.8 (속임, 보상)
G는 판별자의 점수를 올리는 방향으로, D는 그 점수를 낮추는 방향으로, 정확히 반대 목표를 최적화한다.

§3 · 손실 균형
생성자 전체 손실: L1 + SSIM + λ·adv
$$\mathcal{L}_G=\textcolor{#1f3a5f}{w_{1}\,\mathcal{L}_{\text{L1}}}\;+\;\textcolor{#475067}{w_{s}\,\mathcal{L}_{\text{SSIM}}}\;+\;\textcolor{#d4760f}{\lambda\,\mathcal{L}_G^{\text{adv}}}$$
정확도 구조 사실감
L1 · $w_1 = 1.0$
정확도 · 정답에 근접
이 항이 없으면 정답과 무관한 출력이 된다. 보간의 기준 항이다.
SSIM · $w_s = 0.3$
구조 · 패턴 유사성
W2에서 평가지표였던 SSIM을 손실 항으로 추가한다. 밝기·대비·구조의 유사성을 반영한다.
Adversarial · $\lambda \approx 0.1$
사실감 · 회색에 벌점
작은 가중치로 더한다. 실제 연구도 0.09–0.13 범위다. 사실감은 정확도 위에 더하는 항이다.
세 손실항의 가중 기여 · L1(w=1.0)·SSIM(w_s=0.3)·adv(λ=0.1) → 가중합 L_G=0.276 · 가운데 λ≈0.1에서 선명하면서 정확(노트북 §6.5에서 sweep)

§4 · 기법
안정화 기법
① warmup
처음 몇 epoch은 λ=0으로 재구성만 학습하고, 기본 성능이 확보된 뒤 판별자를 추가한다.
② 작은 λ + 감쇠
적대 손실은 ≈0.1로 시작해 후반에 서서히 줄인다. 학습 후반은 정확도 항이 주도한다.
③ spectral norm
D 각 층의 가중치를 최대 특이값으로 나눠 $\|D\|_{\text{Lip}}\le 1$로 만들어, 판별자 우위를 구조적으로 억제한다.
④ 균형 잡힌 학습률
G·D 모두 2e-4, β₁=0.5로 설정해, 한쪽만 빠르게 학습되지 않게 한다.
⑤ 곡선 모니터링
D 손실이 0에 붙으면 λ를 낮추거나 D 학습을 늦춘다. 곡선을 보며 조정한다.
⑥ detach
D 갱신 시 G(x).detach()로, 판별자 학습이 생성자를 갱신하지 않게 한다.
여섯 기법 모두 실습 함수 train_gan( ) 에 구현되어 있다. 노트북에서는 warmup 길이와 λ만 바꿔도 안정성 변화를 관찰할 수 있다.
