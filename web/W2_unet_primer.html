THE BIG IDEA

신경망 = "함수"를 데이터로 배우는 것

모델이 하는 일
$\hat{y} = f(x\,;\,\theta)$
$x$ : 입력 (우리 경우 = 앞·뒤 슬라이스)
$\hat{y}$ : 예측 (가운데 슬라이스)
$\theta$ : 가중치 — 학습으로 정하는 수많은 숫자
$f$ : 구조 (우리 경우 = U-Net)
한국어로 풀면
"입력 $x$를 넣으면 출력 $\hat{y}$가 나오는 기계가 있는데, 그 기계의 손잡이($\theta$)를 데이터를 보며 맞춰 간다." 학습 = 손잡이 맞추기.
우리의 목표: 예측 $\hat{y}$가 진짜 정답 $y$(원본 슬라이스)와 최대한 같아지도록 $\theta$를 찾는 것.

04 / 24
BUILDING BLOCK

가장 작은 단위 — 선형 계층

입력에 가중치를 곱하고 더한다
$y = W x + b$
$W$ : 가중치 행렬 (곱하는 양)
$b$ : 편향 (bias, 더하는 양)
학습으로 정해지는 $\theta = \{W, b\}$
예: 3개 입력 → 2개 출력
$\begin{bmatrix} y_1 \\ y_2 \end{bmatrix} = \begin{bmatrix} w_{11} & w_{12} & w_{13} \\ w_{21} & w_{22} & w_{23} \end{bmatrix}\!\begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}$
합성곱(Conv)도 결국 "위치마다 가중치를 곱해 더하는" 이 연산의 특별한 형태입니다 (§2에서).

ACTIVATION

비선형 — 곡선을 그릴 수 있게

선형 계층만 쌓으면 여전히 직선밖에 못 그립니다. 사이사이 비선형 함수를 넣어야 복잡한 모양을 배웁니다.

ReLU
$\max(0,\,x)$
음수는 0으로, 양수는 그대로. 가장 흔함.
LeakyReLU
$\max(0.1x,\,x)$
음수도 살짝 통과. 우리 ConvBlock이 사용 (기울기 0.1).
Sigmoid
$\dfrac{1}{1+e^{-x}}$
출력을 0~1로 누름. U-Net 마지막에 사용 (pore 확률).

06 / 24
LOSS

손실 — "얼마나 틀렸나"를 숫자로

L1 손실 (절대오차) — 우리 W2 기본
$L_1 = \dfrac{1}{N}\sum_{i=1}^{N} \lvert \hat{y}_i - y_i \rvert$
L2 손실 (제곱오차, MSE)
$L_2 = \dfrac{1}{N}\sum_{i=1}^{N} (\hat{y}_i - y_i)^2$
한국어로 풀면
모든 픽셀에서 "예측 $\hat{y}_i$ 와 정답 $y_i$ 의 차이"를 재서 평균낸 값. 0에 가까울수록 잘 맞춘 것.
L1 vs L2: L2는 큰 오차를 제곱해 더 세게 벌점 → 선명하지만 outlier에 민감. L1은 더 안정적·부드러움. 학습은 이 $L$ 을 줄이는 과정.
Digital Rock · U-Net 기초 해설
07 / 24
GRADIENT DESCENT

학습 = 손실을 줄이는 방향으로 한 걸음

가중치 갱신 규칙
$\theta \;\leftarrow\; \theta \;-\; \eta \, \dfrac{\partial L}{\partial \theta}$
$\dfrac{\partial L}{\partial \theta}$ (gradient) : $\theta$를 조금 바꾸면 $L$이 어디로 변하는지 = 기울기
$\eta$ (learning rate) : 한 걸음의 크기 (우리 코드 $\eta=10^{-3}$)
손실 골짜기를 따라 내려간다
Digital Rock · U-Net 기초 해설
08 / 24
BACKPROPAGATION

역전파 — 기울기를 연쇄법칙으로 계산

연쇄법칙 (chain rule)
$\dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial \hat{y}} \cdot \dfrac{\partial \hat{y}}{\partial w}$
출력 쪽 오차를 입력 쪽으로 거꾸로 곱해 가며 각 가중치가 손실에 준 책임(기울기)을 구합니다.
PyTorch가 자동으로 해 준다
loss.backward() 한 줄이면 모든 $\dfrac{\partial L}{\partial w}$ 가 자동 계산됩니다. 우리는 수식을 직접 미분할 필요 없이 구조·손실·학습률만 고르면 됩니다.
loss.backward() # 기울기 자동 계산 optimizer.step() # θ ← θ − η·기울기

THE OPERATION

합성곱 — 국소 가중합

출력 한 칸 = 커널 $K$ 와 겹친 입력 $I$ 의 가중합
$(I * K)(i,j) = \displaystyle\sum_{m}\sum_{n} I(i{+}m,\, j{+}n)\,K(m,n)$
3×3 커널이 이미지 위를 한 칸씩 미끄러지며, 겹친 9개 픽셀에 각자의 가중치를 곱해 더합니다. 같은 커널을 전체에 공유 → 위치가 달라도 같은 패턴(엣지·텍스처)을 검출하고, 파라미터가 적습니다.

CHANNELS

채널 — 여러 종류의 패턴 검출기

▦
입력 채널 → 출력 채널
예: 입력 2채널(앞·뒤 슬라이스) → 출력 8채널. 출력 채널 하나 = 커널 하나가 만든 feature map.
▤
feature map
"이 위치에 이 패턴이 얼마나 있나"를 담은 지도. 채널이 많을수록 다양한 패턴을 본다.
⬚
padding
가장자리를 0으로 채워 크기를 유지 (우리 코드 padding=1 → 3×3에서 크기 보존).

BATCH NORMALIZATION

BatchNorm — 학습을 안정시키는 정규화

각 채널을 평균 0·분산 1로 정규화
$\hat{x} = \dfrac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}$
$\mu, \sigma^2$ : batch 안에서 잰 평균·분산
$\epsilon$ : 0으로 나눔 방지용 아주 작은 수
왜 필요한가
층을 지날수록 값의 크기가 들쭉날쭉해지면 학습이 불안정합니다. 매 층에서 값을 "비슷한 크기"로 맞춰 주면 더 빠르고 안정적으로 학습됩니다.
nn.BatchNorm2d(out_ch)

SKIP-CONNECTION

건너뛰기 — encoder의 detail을 직접 전달

class UpBlock(nn.Module): def forward(self, x, skip): x = self.up(x) # 크기 ↑ x = torch.cat([x, skip], dim=1) # ↑ encoder의 같은 크기 feature를 채널로 합침 return self.conv(x)
dim=1 = 채널 축. 합치면 채널이 두 배가 되고, 이어지는 ConvBlock이 그걸 다시 정리합니다.
왜 중요한가
압축하며 잃어버린 엣지·경계 detail을 decoder가 그대로 돌려받습니다. skip이 없으면 → 흐릿한 복원, 있으면 → 선명한 pore 경계.

DATA · SliceDataset

학습 데이터 만들기 — triplet

누락된 z 하나마다, 앞·뒤 측정 슬라이스를 찾는다
$\text{before} = z - (z \bmod k), \quad \text{after} = \text{before} + k$
$z \bmod k$ = z를 k로 나눈 나머지. 예) $k{=}2,\ z{=}5$ → before$=4$, after$=6$. 입력 $[\,$slice$_4$, slice$_6\,]$ → 정답 slice$_5$.
for z in range(Z): if z % k == 0: continue # 측정됨→건너뜀 before = z - (z % k) after = before + k # 입력 [bb[before], bb[after]] → 정답 bb[z]
이렇게 만든 (before, 정답, after) 한 묶음이 학습 sample 하나. 부피 전체에서 수백 개가 자동 생성됩니다.
