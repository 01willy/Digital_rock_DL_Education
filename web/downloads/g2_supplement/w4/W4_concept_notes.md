# W4 개념 풀이 — attention · Swin · 3D CNN · diffusion · 공정 비교

노트북을 실행하기 전이나 막히는 부분이 있을 때 읽는 보충 설명이다.

## 0. 이번 주의 위치: 개선 축 vs 검증 축

우리 pix2pix 모델은 손실·입력·GAN(W3)으로 개선해 왔다(개선 축). 구조의 뼈대인 2D 합성곱은
바꾼 적이 없다. 이번 주는 우리 접근이 좋은지 확인하기 위해 대안 구조(Transformer 계열 Swin·
3D CNN·diffusion)와 같은 조건에서 비교한다(검증 축). 이 구조들은 채택 대상이 아니라
비교 기준(baseline)이다. 대규모 결과에서 우리 모델(MAPS)이 이 비교군들을 앞선다.

## 1. 합성곱의 시야와 한계

합성곱은 각 위치에서 주변 3×3 만 보고, 같은 가중치 9개(×채널)를 모든 위치에 재사용한다.
이 "지역성 + 가중치 공유"는 적은 파라미터로 이미지의 지역 패턴을 잘 잡는다. 대신 멀리 있는
픽셀을 보려면 층을 많이 쌓아야 하고(수용 영역은 층당 2씩 증가), 가중치가 내용과 무관하게
고정이라 "이 픽셀과 비슷한 픽셀을 골라서 참고"하는 동작은 하지 못한다.

## 2. attention 한 줄 정의

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}}\right)V$$

- **Q(질의)·K(색인)·V(내용)**: 같은 입력 토큰에서 서로 다른 선형 변환으로 만든 세 행렬.
- **QKᵀ**: 모든 토큰 쌍의 점곱 유사도. "나(Q)와 비슷한 색인(K)은 누구인가"를 잰다.
- **÷√d**: 차원 d 가 크면 점곱의 분산이 d 에 비례해 커진다. 나눠 주지 않으면 softmax 가
  포화되어(한 토큰에 가중치 1.0) 기울기가 사라진다.
- **softmax**: 각 행을 합=1 확률로 바꾼다. 이것이 가중치다.
- **×V**: 가중치로 내용(V)의 가중 평균을 낸다. "비슷한 토큰의 내용을 많이 섞은 새 표현".

합성곱과의 차이는 가중치의 출처다. 합성곱의 가중치는 학습이 끝나면 고정이고 위치가 정한다.
attention 의 가중치는 입력 내용에 따라 실행 시점마다 다시 계산된다.

## 3. 왜 창(window)인가

attention 비용은 토큰 쌍 수 N² 이다. 256×256 픽셀을 전부 토큰으로 쓰면 65,536² ≈ 43억 쌍.
Swin 의 해법은 두 단계다.

1. 패치 임베딩: 4×4 픽셀을 토큰 하나로(conv stride 4) → 4,096 토큰.
2. 창 분할: 8×8 창 64개로 나누고 attention 은 창 안에서만 → 64×64² = 262,144 쌍 (1/64).

창 안에만 갇히면 경계 너머 정보가 끊긴다. 그래서 다음 블록에서 창을 절반(4토큰) 이동시켜
경계에 걸쳤던 토큰들이 같은 창에 들어오게 한다. 고정 창(W-MSA)과 이동 창(SW-MSA)을
번갈아 쌓는 것이 Swin 의 기본 단위다.

## 4. 3D 합성곱과 공정한 입력

3D 합성곱은 3×3×3 커널로 슬라이스 안(x·y)과 사이(z)를 함께 본다. 공극은 z 방향으로 이어진
3차원 구조이므로 원리적으로 유리하다. 대신 같은 채널 수 기준 파라미터가 3배, 연산은 깊이
방향만큼 더 든다. 같은 시간 예산에서는 소화하는 학습량이 적어진다.

**공정한 입력**: 3D 모델의 입력 부피에는 2D 모델과 같은 정보(이웃 t±k 두 장)만 넣어야 한다.
`Slice3DDataset` 은 깊이 2k+1 부피에서 맨 앞·맨 뒤 면만 채우고 나머지를 0으로 둔다(+마스크
채널). 만약 t±1 슬라이스를 입력에 넣으면 예측 대상 바로 옆의 정답 정보가 새어 들어가
지표가 크게 부풀며, 이것은 모델의 실력이 아니다.

## 5. 공정 비교의 세 원칙

1. 같은 데이터 (같은 volume, 같은 triplet)
2. 같은 입력 정보 (이웃 t±k 두 장뿐)
3. 같은 시간 예산 (wall-clock. 빠른 구조는 그만큼 epoch 을 더 돈다)

파라미터 수만 맞추는 것으로는 부족하다. 구조마다 한 스텝의 비용이 다르기 때문이다.
또 학습 설정(학습률·optimizer)은 구조마다 안정적인 값이 달라, 각 구조에 맞는 표준 설정을
쓰는 것이 관례다. `benchmark_models` 는 합성곱 계열에 Adam, transformer 계열에
AdamW+gradient clipping 을 쓴다.

## 6. 결과를 읽는 법

- **|Δφ|**: 물성(공극률) 보존. 낮을수록 좋다.
- **SSIM**: 구조 유사도. 높을수록 좋다.
- **epochs**: 같은 시간 동안 소화한 학습량. 구조의 속도를 보여 준다.
- 좋은 질문은 "누가 이겼나"가 아니라 "**무엇을 내주고 무엇을 얻었나**"다. 예: 3D 는 부피
  문맥을 얻는 대신 같은 시간의 학습량을 내준다.

## 7. 이 규모의 결과와 대규모의 결과, 그리고 우리 모델

작은 모델·짧은 예산(이 노트북)에서는 2D 합성곱의 귀납 편향이 유리하다. 노트북에서는 우리
방식(2D UNet + GAN)이 물성(|Δφ|) 보존에서 앞서는 경향을 보인다. 대규모 실험(사암 1000³,
배포-동등)에서는 우리 모델 MAPS(pix2pix + GAN + 다축 융합)가 SSIM 0.935·|Δφ| 0.122%p로
모든 비교군을 앞선다: 2D UNet 0.932/0.265, SwinUNet 0.926/0.343, 3D UNet 0.914/0.402,
diffusion 0.510/14.8(off-Pareto). SwinUNet 은 파라미터 1/22 로 2D UNet 에 근접하지만,
같은 예산에서 키운다고 우리 모델을 넘지는 못한다. 결론은, 최고의 구조가 따로 있는 게 아니라
문제·데이터·예산에 맞는 구조가 있고, 우리 접근이 이 문제에서 앞선다는 것이다.

## 8. diffusion

diffusion 은 노이즈에서 시작해 신경망을 수십 번 반복 실행하며 복원하는 생성 모델이다. GAN 과
함께 생성 모델의 양대 축이라 비교군에 포함한다. 다만 이 문제에서는 한 장 복원에 수십 스텝이
필요하고 학습 연산도 커서, 우리 예산에서는 미수렴하고 추론도 약 15배 느리다. 성능과 비용을
함께 보면 off-Pareto, 즉 실전에서 선택할 이유가 없는 위치다. 원리상 불가능이 아니라 이 문제·
이 예산에서 경쟁력이 없다는 뜻이다.
