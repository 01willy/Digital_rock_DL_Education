# W1 보조 노트 — 개념 풀이

본 노트는 W1 본 자료(노트북·핸드아웃)에서 빠르게 지나가는 개념들을 좀 더 풀어 설명한 것입니다. 본 자료를 먼저 본 뒤 막히는 개념이 있을 때 참조하세요.

---

## 1. Voxel — 3차원 공간의 픽셀

평소 보는 사진은 2차원 픽셀 격자입니다. 한 픽셀은 (가로, 세로) 두 개의 좌표로 위치가 정해집니다.

3D 부피 데이터는 한 차원을 더해 (깊이, 높이, 너비) 세 좌표로 위치가 정해지는 **voxel** 격자로 표현됩니다. 한 voxel은 작은 정육면체 한 칸이고, 우리 데이터에서 한 칸의 한 변은 `2.25 마이크로미터(μm)`입니다.

```
2D 이미지:  img[y, x]              ← 두 좌표
3D 부피:    volume[z, y, x]        ← 세 좌표
```

> 비유: 사진 한 장이 영화 한 프레임이라면, 3D 부피는 \"여러 프레임을 차곡차곡 쌓은 묶음\"과 비슷합니다.

---

## 2. Slice — 3D 부피를 한 평면으로 자른 단면

3D 부피는 한 번에 보기 어렵습니다. 한 방향으로 자르면 2D 이미지가 됩니다 — 이를 **slice** 라고 부릅니다.

세 가지 자르는 방향:
- `volume[z, :, :]` → **z축 slice** (XY 평면, micro-CT의 측정 방향과 같음)
- `volume[:, y, :]` → **y축 slice** (ZX 평면)
- `volume[:, :, x]` → **x축 slice** (ZY 평면)

같은 부피라도 어느 방향에서 자르냐에 따라 보이는 패턴이 다릅니다. 본 W1 노트북의 §3에서 세 축 결과를 직접 확인합니다.

---

## 3. Porosity (φ, 공극률) — 가장 기본적인 물리량

암석의 \"빈 공간 비율\". 본 데이터에서는 voxel 값이 0(고체) 또는 1(공극)이므로:

```python
porosity = (값이 1인 voxel 수) / (전체 voxel 수)
         = numpy 배열의 평균 (.mean())
```

왜 중요한가:
- 암석이 얼마나 많은 액체/기체를 저장할 수 있는지 결정
- 보간 결과가 \"잘 됐는지\" 평가할 때 1차 metric — 복원된 부피의 φ가 원본과 비슷해야 합니다

---

## 4. Normalization — 왜 [0, 1] 로 만드는가?

`uint8` 타입은 0~255의 정수 값을 가집니다. 딥러닝 모델 입력으로 그대로 쓰면:
- 값의 크기가 너무 커서 모델 가중치가 불안정
- 학습 초기에 출력이 발산하기 쉬움

그래서 `vol / 255.0` 으로 **0~1 사이의 float** 으로 변환합니다. 이렇게 하면 모든 layer의 출력이 비슷한 크기를 유지해 학습이 안정적입니다. (W2에서 이 정규화가 모델 입력 직전에 적용되는 것을 직접 보게 됩니다.)

본 W1 데이터는 이미 0 또는 1뿐이라 정규화가 trivial하지만, 함수는 W2 이후를 위해 미리 익혀둡니다.

---

## 5. Otsu threshold — 자동 임계값

원본 micro-CT 영상은 **grayscale** (0~255 값이 다양함). 이를 \"공극\" 과 \"고체\" 두 가지로 분류 (segmentation) 하려면 임계값(threshold) `t`가 필요합니다:
- 값 > t → 공극
- 값 ≤ t → 고체

Otsu 알고리즘은 이 `t`를 **자동으로** 고릅니다. 히스토그램의 두 봉우리 사이의 골짜기를 찾는 방식입니다.

본 W1 데이터는 이미 binary(0/1뿐)라 Otsu가 `t≈0.5`를 반환합니다 — 의미 있는 결과는 아니지만, W4 grayscale 데이터를 만나면 Otsu의 가치가 살아납니다.

W1 노트북의 \"인공 grayscale\" 셀에서는 일부러 노이즈를 더해 Otsu가 어떻게 동작하는지 시각화합니다.

---

## 6. 이웃 거리 k — 슬라이스 사이를 채우는 문제

micro-CT 스캔은 시간·비용이 비싸서, **모든 z 슬라이스를 빽빽이 측정하지 않고 듬성듬성 측정** 한 뒤 사이의 슬라이스를 예측하는 전략을 씁니다.

이때 **이웃 거리 k** 를 정합니다 — 슬라이스 `t` 를 두 이웃 `t−k`, `t+k` 로부터 예측합니다.

- k=1 → 바로 옆 슬라이스(t±1)로 예측 (가장 쉬움)
- k=3 → t±3 으로 예측 → 한 칸 간격이 듬성해져 측정 부담 75% 절감
- k=5 → t±5 으로 예측 → 측정 부담 83% 절감

(이웃 거리 k일 때 한 칸 간격은 (k+1)배로 듬성해지므로 측정 부담은 `1/(k+1)` 로 줄어듭니다.)

문제: **이웃 사이의 슬라이스를 어떻게 정확히 예측할 것인가?** — 본 코스 전체의 핵심 질문입니다. 이웃이 멀수록(큰 k) 어려워집니다.

W1에서는 가장 단순한 두 방법 (Linear, Cubic spline 보간) 으로 시도하고, W2 이후 deep learning으로 더 잘 예측하는 방법을 배웁니다.

---

## 7. Linear vs Cubic spline 보간

양옆 이웃 슬라이스(t±k)로 가운데 슬라이스 t 를 예측하는 두 가지 방법:

**Linear (선형) 보간**
- 두 이웃 슬라이스의 값을 직선으로 연결 (1차 함수)
- 두 이웃이 같은 거리(±k)에 있으므로 가운데는 α=0.5: `예측 = 0.5·(vol[t−k] + vol[t+k])`
- 단순하고 빠름. 곡선이 아니라 직선이라 부드럽지 않음

**Cubic spline (3차 곡선) 보간**
- t±k, t±3k 의 4개 슬라이스를 통과하는 부드러운 3차 곡선
- 같은 이웃 거리 k에서도 더 자연스러운 결과
- 단점: 계산이 좀 더 무거움. \"oscillation\" (꿀렁임)이 가끔 발생

본 W1 노트북에서 두 방법의 결과를 같은 그림에서 비교하고, 어느 도메인·k에서 차이가 명확한지 직접 확인합니다.

---

## 8. 평가 지표 2종 — |Δφ|, SSIM

예측된 슬라이스가 \"얼마나 정확한가\"를 측정하는 두 가지 방법 (평가는 예측 대상 슬라이스 t ∈ [k, Z−k) 에서만):

**|Δφ| (공극률 오차)**
- `|φ(예측) − φ(원본)|`, %p(퍼센트 포인트) 단위
- 값이 작을수록 좋음. 0이면 공극률 완벽 일치
- 1차 평가 지표

**SSIM (Structural Similarity Index)**
- 0~1 범위, 1에 가까울수록 두 이미지가 비슷
- 픽셀 값뿐 아니라 \"구조의 유사성\" 도 보는 지표 (대비, 패턴)

두 metric을 함께 보는 이유: **단일 metric으로는 \"좋은 예측\" 을 정의하기 어려움**. 예를 들어 |Δφ|가 0이라도 모양이 완전히 다를 수 있습니다. `eval_targets(rec, orig, k)` 가 두 값을 dict(`'dphi_pp'`, `'ssim'`)로 한 번에 반환합니다.

## 9. Slab (슬랩) — 부피의 두꺼운 조각

전체 공극률 한 숫자만으로는 \"부피의 위쪽과 아래쪽이 같은지\" 알 수 없습니다. 부피를 한 방향으로 **N개의 슬랩** 으로 나누고 각 슬랩의 공극률을 보면, 부피가 균질한지 (등방성에 가까운지) 확인할 수 있습니다.

```python
volume.shape = (256, 256, 256)
n_slabs = 8
→ 각 slab 두께 = 32 voxel (z 방향)
→ 8개의 공극률 값
```

세 축(z, y, x) 모두에 대해 슬랩 프로파일이 비슷하면 부피가 비교적 균질하다고 판단합니다.
